## ⚙️ Local Development Setup

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/shahidiqbal4261-cpu/portfolio1.git
   cd portfolio1
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Start Development Server**:
   ```bash
   npm run dev
   ```

4. **Build for Production**:
   ```bash
   npm run build
   ```

5. **Deploy to GitHub Pages**:
   ```bash
   npm run deploy
   ```
